What I learnt

1.What does the action attribute do ?

An action attribute gives additional information about an HTML element.

2.What does method attribute do ?

Method attribute, specifies how the browser should submit the form data.

3.Why is GET commonly useful for a search form ?

It is useful for form because the search information can appear in URL.

4.Why might post be used for a registration form?

Post is commonly used for sending registration information to a server.

5.Does using POST automatically make information secure?

No, it doesn't.

Why not ?

POST sends form data in the request body rather than putting it in the URL.
